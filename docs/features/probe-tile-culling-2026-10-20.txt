Workgroup-local reflection probe culling - 2026-10-20

Change
The8x8screen-space reflection filter now constructs a conservative probe mask
shared by its64invocations. Reconstructed, receiver-biased world positions bound
actual surfaces in the tile. Each probe tests that AABB against its oriented
influence bounds using affine support intervals with a float-error guard. Only
proven separation rejects a probe. Invalid positions fail open to a full scan;
empty/sky/partial workgroups participate before divergent returns.

One32bit mask matches the existing32probe storage contract. Set bits are consumed
in original ascending order. Per-pixel containment, authored priority, parallax,
roughness and feather blending remain authoritative and unchanged. No extra GPU
pass, persistent candidate list, descriptor, public ABI, cache format or setting.
About1KiB shared receiver scratch per workgroup. Water/viewmodel shaders retain
the original contiguous probe walk via a compile-time variant of the shared body;
no duplicate shading implementation or runtime feature switch is introduced.

Verification
Release build passes. Eight GPU/integration suites pass with Vulkan validation
and synchronization checking: oriented probe sampling, viewmodelSSR, viewmodel
environment materials, SSR/MSAA guides, SSR/probe blending, sky fallback, hardware
reflection transport and water environment lighting. The sampling fixture includes
all32mask positions, distant translated volumes, oriented boxes, priorities,
roughness, boundaries and partial workgroups. Six shader backends regenerate,
compare and validate. Byte-level stage comparison confirms only forward ssrFilter
changes in production; water and water-ray stages are identical to baseline.
A shared-helper cleanup initially exposed4argument callers during regeneration;
the final compile-time variants preserve those callers and all checks pass.
