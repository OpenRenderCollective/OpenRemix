Skip known-empty styled merge tiles - 2026-10-20

Change
Sparse direct/indirect group merging now supplies a conservative surface-tile
occupancy callback to the streaming builder. Only when both validated input maps
mark a tile black can the builder skip its texel callbacks and encoding. Occupied
tiles retain the same decode/add/encode order, including quantization and signed
coefficients. Probe traversal remains unchanged. Existing callers without occupancy
retain exhaustive sampling. No dense atlas, new runtime setting, cache revision,
shader or retained GPU allocation. Cancellation is checked even on skipped tiles;
budget checks and publication remain all-or-nothing.

Evidence
Release build and four suites pass: sparse styled SH, grouped direct captures,
bake-cache integrity and GPU surface/probe reconstruction. GPU checks use Vulkan
validation and synchronization validation. Regression coverage compares the complete
encoded merge with exhaustive traversal; it includes disjoint/overlapping support,
probe-only styles, signed values, partial17x17 edge tiles on two pages, storage
exhaustion and cancellation. The edge fixture reduces surface callbacks578->1 with
identical serialized output. Malformed input validation remains before occupancy.
